# ADJUTORIX — Existing native MIDIA-AI portfolio browser

The MIDIA-AI panel within the **existing** ADJUTORIX Guided Mission Control presents a paginated GitHub owner/organization repository catalogue from the **existing** authenticated Electron-main-to-MIDIA-AI UNIX socket. The preload receives only bounded metadata; no HMAC keys, OAuth tokens or arbitrary filesystem access. A catalogued repo is **not** automatically an authorized source project. An explicitly selected ChatGPT session is still required for source file reading, and all governed work requires local owner approval.

If the MIDIA-AI gateway still uses the older tool catalogue or the owner has not run metadata discovery, the panel displays the catalog as pending while leaving the existing verified ADJUTORIX connection functional. This is not a new application, gateway, paid service or automatic bulk source-grant workflow.
